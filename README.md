# QuantiValue V2

Radically redesigned Vite + React landing page.

Cloudflare bindings required:
- `VISITS` → KV namespace `quantivalue-visits`
- `OFFERS_DB` → D1 database `quantivalue-offers`

Build:
- Command: `npm run build`
- Output: `dist`

The existing `/api/views` and `/api/offer` Pages Functions are preserved.
